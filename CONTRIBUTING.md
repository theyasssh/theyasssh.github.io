# Contributing to Yash Khatri's Portfolio

Thank you for your interest in contributing! While this is a personal portfolio website, contributions for bug fixes, performance improvements, and feature enhancements are welcome.

## 🐛 Reporting Bugs

If you find a bug, please open an issue with:
- **Clear title** describing the problem
- **Steps to reproduce** the bug
- **Expected behavior** vs actual behavior
- **Screenshots** (if applicable)
- **Browser and OS** information

## 💡 Suggesting Enhancements

For feature suggestions, please open an issue with:
- **Clear description** of the enhancement
- **Use case** - why would this be useful?
- **Proposed implementation** (if you have ideas)

## 🔧 Development Process

1. **Fork the repository**
   ```bash
   git clone https://github.com/theyasssh/portfolio.git
   cd portfolio
   ```

2. **Create a feature branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make your changes**
   - Edit `index.html` as needed
   - Test in multiple browsers
   - Ensure responsive design works

4. **Test thoroughly**
   - Test on Chrome, Firefox, Safari
   - Test on mobile devices
   - Check all animations work
   - Verify all links function

5. **Commit your changes**
   ```bash
   git add .
   git commit -m "Add: Brief description of changes"
   ```

6. **Push to your fork**
   ```bash
   git push origin feature/your-feature-name
   ```

7. **Submit a Pull Request**
   - Describe what you changed and why
   - Reference any related issues
   - Include screenshots for visual changes

## 📝 Code Style

### HTML
- Use semantic HTML5 elements
- Keep proper indentation (2 spaces)
- Add ARIA labels for accessibility
- Comment complex sections

### CSS
- Follow existing naming conventions
- Use CSS custom properties for colors
- Keep specificity low
- Add comments for complex styles
- Group related styles together

### JavaScript
- Use ES6+ features
- Keep functions small and focused
- Add comments for complex logic
- Use meaningful variable names
- Handle errors gracefully

## ✅ Pull Request Checklist

Before submitting, ensure:
- [ ] Code follows existing style
- [ ] All links work correctly
- [ ] Animations run smoothly
- [ ] Website is responsive
- [ ] No console errors
- [ ] Tested on multiple browsers
- [ ] Tested on mobile devices
- [ ] No personal information exposed

## 🚫 What NOT to Contribute

Please avoid:
- Personal content changes (this is my portfolio!)
- Breaking existing functionality
- Adding external dependencies without discussion
- Large refactors without prior approval
- Unrelated features
